# Vibe Chat
Standalone Android messenger starter project. No Higgsfield SDK, auth, credits, or AI integration.

## Current UI
- Chats
- Contacts
- Profile
- 1-to-1 chat screen
- Online indicator
- Message composer

## Next production layer
Backend with independent authentication, PostgreSQL, WebSocket realtime messaging, object storage, push notifications, voice messages, groups, moderation, and encryption strategy.

## Build
Requires Android SDK + Gradle/Android Studio. This environment currently has Java but no Android SDK/Gradle, so APK compilation is not performed here.
